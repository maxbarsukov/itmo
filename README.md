<h3>👋 Привет, студент!</h3>

Этот проект создан для студентов СППО и смежных направлений, а также для тех, кто только только планирует поступать в ИТМО.

В каждой папке (формата `<семестр> <предмет>`) содержится описание предмета (разъяснения по непонятным моментам, решения проблем, которые могут возникнуть в ходе обучения, и др.), а также любые другие материалы по профильным (и не только) предметам по **направлению СППО** и **кафедре ВТ**:

- :woman_technologist: лабораторные работы;
- :memo: конспекты лекций и презентации;
- :bar_chart: контрольные и рубежные работы;
- :house: домашние работы;
- :test_tube: тесты;
- :mortar_board: экзамены и зачёты.

Если что-то используете, пожалуйста **подписывайтесь :bell:** и **ставьте :star:**, чтобы не потерять. <sub>(мне будет очень приятно)</sub>

> [!TIP]
> Чтобы скачать какую-то папку, не обязательно клонировать репозиторий целиком. \
> Вы можете скачать любой каталог как `.zip`-архив на веб-сайте [itmo.maxbarsukov.ru/repo/](https://itmo.maxbarsukov.ru/repo/).

Я буду рад увидеть ваши идеи, предложения и любые материалы, которые вы хотели бы добавить в репозиторий. Не стесняйтесь отправлять **Pull request** :mailbox_with_mail:, чтобы я добавил вашу информацию!

На любые вопросы я с радостью отвечу в telegram ([@nyapsilon](https://t.me/nyapsilon)) :wink:

## Содействие <a name="contributing"></a>

Сообщения об ошибках и запросы на вытягивание приветствуются на GitHub по адресу https://github.com/maxbarsukov/itmo.
Этот проект задуман как безопасное и гостеприимное пространство для совместной работы, и ожидается, что участники будут придерживаться [кодекса поведения](https://github.com/maxbarsukov/itmo/blob/master/CODE_OF_CONDUCT.md).
